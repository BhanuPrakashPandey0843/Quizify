# Quizify Frontend

The frontend is a polished React application providing an immersive user experience.

##  UI/UX Highlights
*   **Modern Design**: Clean layout with consistent typography (`Josefin Sans`) and color palette (Primary Blue `#1e40af`).
*   **Smooth Scrolling**: Implemented using **Lenis** for a premium feel.
*   **Animations**: **GSAP** is used for scroll-triggered animations and interactions.
*   **Responsive**: Fully optimized for Mobile, Tablet, and Desktop.

##  Tech Stack
*   **React**
*   **Tailwind CSS**
*   **React Router v6**
*   **GSAP**
*   **Lenis**
*   **React Icons**

##  Setup & Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```
2.  **Start Development Server**:
    ```bash
    npm start
    ```
    The app will open at `http://localhost:3000`.

##  Key Directories
*   `src/Components`: Reusable UI components (Navbar, Footer, Hero, etc.).
*   `src/Pages`: Page-level components (Landing, Login, Signup, Exam).
*   `src/assets`: Images and static assets.

##  Key Components
*   **LandingPage**: Showcases the platform features.
*   **QuizStory**: Animated section telling the story of Quizify.
*   **Signup/Login**: Polished auth screens.
